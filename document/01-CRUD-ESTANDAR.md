## 🗄️ PASO 0 — Crear la tabla con SQL (template reciclable)

### SQL estándar para crear cualquier tabla

Ve a **Supabase Studio → SQL Editor → New query**, copia esto y ejecuta (`Run`):

```sql
-- Cambia 'cursos' por el nombre de tu tabla
CREATE TABLE IF NOT EXISTS cursos (
  id         bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nombre     text NOT NULL,
  modalidad  text NOT NULL,
  horas      int4 NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

### ¿Qué partes cambian?

| Parte | ¿Cambia? | Ejemplo |
|-------|----------|---------|
| `cursos` | ✅ SÍ | `'productos'`, `'libros'`, `'empleados'`... |
| `nombre` | ✅ SÍ | `'titulo'`, `'email'`, `'descripcion'`... |
| `modalidad` | ✅ SÍ | `'categoria'`, `'estado'`, `'tipo'`... |
| `horas` | ✅ SÍ | `'precio'`, `'stock'`, `'edad'`... |
| `int4` | ⚠️ Opcional | Si el campo es texto → `text`, si es número → `int4` o `numeric`, si es booleano → `boolean` |
| `id` | ❌ NO | Siempre igual |
| `created_at` | ❌ NO | Siempre igual |
| `PRIMARY KEY` | ❌ NO | Siempre igual |
| `DEFAULT now()` | ❌ NO | Siempre igual |

### Ejemplo adaptado a "productos"

```sql
CREATE TABLE IF NOT EXISTS productos (
  id          bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nombre      text NOT NULL,
  categoria   text NOT NULL,
  precio      numeric(8,2) NOT NULL,
  stock       int4 NOT NULL DEFAULT 0,
  created_at  timestamptz NOT NULL DEFAULT now()
);
```

### Ejemplo adaptado a "empleados"

```sql
CREATE TABLE IF NOT EXISTS empleados (
  id         bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nombre     text NOT NULL,
  departamento text NOT NULL,
  salario    numeric(8,2) NOT NULL,
  activo     boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now()
);
```

> 💡 **Tip**: `GENERATED BY DEFAULT AS IDENTITY` es lo moderno en PostgreSQL. Es como `serial` pero mejor. Genera automáticamente 1, 2, 3... sin que tú lo pongas.

## 🚀 PASO 2 — Template CRUD completo (copia y pega esto)

Crea el archivo en tu proyecto, por ejemplo: `src/app/cursos/page.js`

```javascript
'use client'

import { useEffect, useState } from 'react'
import { createClient } from '@/utils/supabase/client'

// ═══════════════════════════════════════════════════════════
// 1. CONFIGURACIÓN: SOLO CAMBIA ESTAS 2 COSAS
// ═══════════════════════════════════════════════════════════
const NOMBRE_TABLA = 'cursos'          // ← CAMBIA: nombre de tu tabla
const CAMPOS_FORMULARIO = ['nombre', 'modalidad', 'horas']  // ← CAMBIA: campos

// ═══════════════════════════════════════════════════════════
// 2. ESTADOS: crea un useState por cada campo del formulario
// ═══════════════════════════════════════════════════════════
export default function CrudPage() {
  const [lista, setLista] = useState([])

  // Estados del formulario (uno por cada campo)
  const [nombre, setNombre] = useState('')
  const [modalidad, setModalidad] = useState('presencial')
  const [horas, setHoras] = useState('')

  const supabase = createClient()

  // ═══════════════════════════════════════════════════════════
  // 3. LEER (SELECT): obtiene todas las filas
  // ═══════════════════════════════════════════════════════════
  const fetchDatos = async () => {
    const { data, error } = await supabase
      .from(NOMBRE_TABLA)
      .select('*')
      .order('created_at', { ascending: false })

    if (error) {
      console.error('Error al leer:', error)
    } else {
      setLista(data)
    }
  }

  useEffect(() => {
    fetchDatos()
  }, [])

  // ═══════════════════════════════════════════════════════════
  // 4. CREAR (INSERT): añade una nueva fila
  // ═══════════════════════════════════════════════════════════
  const handleSubmit = async (e) => {
    e.preventDefault()

    // Objeto con los datos a insertar
    const nuevoRegistro = {
      nombre: nombre,
      modalidad: modalidad,
      horas: Number(horas),   // ← Si es número, pon Number()
    }

    const { error } = await supabase
      .from(NOMBRE_TABLA)
      .insert([nuevoRegistro])

    if (error) {
      console.error('Error al insertar:', error)
    } else {
      // Limpiar formulario
      setNombre('')
      setModalidad('presencial')
      setHoras('')
      // Recargar lista
      fetchDatos()
    }
  }

  // ═══════════════════════════════════════════════════════════
  // 5. ELIMINAR (DELETE): borra una fila por su id
  // ═══════════════════════════════════════════════════════════
  const handleDelete = async (id) => {
    const { error } = await supabase
      .from(NOMBRE_TABLA)
      .delete()
      .eq('id', id)

    if (error) {
      console.error('Error al eliminar:', error)
    } else {
      fetchDatos()
    }
  }

  // ═══════════════════════════════════════════════════════════
  // 6. HTML: formulario + tabla
  // ═══════════════════════════════════════════════════════════
  return (
    <div style={{ padding: '2rem', fontFamily: 'Arial' }}>
      <h1>Gestión de {NOMBRE_TABLA}</h1>

      {/* ─── FORMULARIO ─── */}
      <form onSubmit={handleSubmit} style={{ marginBottom: '2rem', display: 'flex', gap: '10px' }}>
        <input
          type="text"
          placeholder="Nombre"
          value={nombre}
          onChange={(e) => setNombre(e.target.value)}
          required
        />

        <select
          value={modalidad}
          onChange={(e) => setModalidad(e.target.value)}
        >
          <option value="presencial">Presencial</option>
          <option value="online">Online</option>
        </select>

        <input
          type="number"
          placeholder="Horas"
          value={horas}
          onChange={(e) => setHoras(e.target.value)}
          required
        />

        <button type="submit">Añadir</button>
      </form>

      {/* ─── TABLA DE RESULTADOS ─── */}
      <table border="1" cellPadding="10" style={{ borderCollapse: 'collapse', width: '100%' }}>
        <thead style={{ backgroundColor: '#f0f0f0' }}>
          <tr>
            <th>ID</th>
            <th>Nombre</th>
            <th>Modalidad</th>
            <th>Horas</th>
            <th>Creado</th>
            <th>Acción</th>
          </tr>
        </thead>
        <tbody>
          {lista.map((item) => (
            <tr key={item.id}>
              <td>{item.id}</td>
              <td>{item.nombre}</td>
              <td>{item.modalidad}</td>
              <td>{item.horas}</td>
              <td>{new Date(item.created_at).toLocaleDateString()}</td>
              <td>
                <button
                  onClick={() => handleDelete(item.id)}
                  style={{ backgroundColor: '#ff4444', color: 'white', border: 'none', padding: '5px 10px', cursor: 'pointer' }}
                >
                  Eliminar
                </button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  )
}
```

## 🐛 ERRORES COMUNES Y SOLUCIONES RÁPIDAS

| Error | Por qué pasa | Solución |
|-------|-------------|----------|
| `useState is not defined` | Olvidaste importar `useState` | `import { useState } from 'react'` |
| `useEffect is not defined` | Olvidaste importar `useEffect` | `import { useEffect } from 'react'` |
| `createClient is not defined` | Ruta de import mal | `import { createClient } from '@/utils/supabase/client'` |
| No aparecen datos | RLS activado | Desactiva RLS en Supabase Studio |
| `insert` falla sin error visible | El campo no existe en la tabla | Revisa que los nombres de campos coincidan EXACTAMENTE |
| `delete` no borra nada | El `id` es undefined | Comprueba que `item.id` exista en la tabla |
| La página se ve sin estilo | Normal, no usamos CSS | El profe no pide diseño, solo funcionalidad |
